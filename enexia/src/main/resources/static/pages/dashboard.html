Donde se guarda el token

Almacen sessionStorage
Clave enexia_token
Duracion Se borra al cerrar la pestana
Se envia como Authorization: Bearer <token>

Con localStorage la sesion sobreviviria al cierre del navegador, pero el token quedaria expuesto por mas tiempo. Ninguno de los dos frena un XSS: para eso hace falta una cookie HttpOnly, prevista para Sprint 2.

Anatomia del token

                

                

                    

                        

                            cabecera
                            Algoritmo de firma y tipo
                        

                        

                            payload
                            sub (email), roles, iat, exp, iss
                        

                        

                            firma
                            HMAC con la clave secreta del servidor
                        

                    

                    

                        Las tres partes viajan en Base64Url, que no es cifrado:
                        cualquiera puede leer el payload. Lo que no puede es alterarlo, porque
                        la firma dejaria de coincidir y el backend rechazaria el token.
