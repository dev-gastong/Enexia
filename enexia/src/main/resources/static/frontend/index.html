Modulo 1: Usuarios y Autenticacion

Banco de pruebas visual del Sprint 1. Cada formulario muestra al lado la respuesta HTTP real del backend: status, cabeceras y JSON.

Registro →

RF-1.1. Alta de Persona Fisica con seleccion de perfil. Valida formato, unicidad de email y DNI, moderacion de texto y asignacion de roles.

Login →

RF-1.2, RF-1.4 y RF-1.6. Emite el JWT, controla el estado de la cuenta y aplica la escala de penalizacion por intentos fallidos.

Antes de empezar

  1. Levantar el backend: cd enexia y luego .\gradlew.bat bootRun (queda en el puerto 8080).
  2. Servir este frontend desde el puerto 8000: cd frontend y luego python -m http.server 8000.
  3. Abrir http://localhost:8000. Abrir el archivo con doble clic NO funciona: el origen file:// lo bloquea la politica CORS del backend.
